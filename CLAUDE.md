# Scripts de Aurora Dex (Tampermonkey)

- Siempre que se cambie un script `Auroradex_*.user.js`, sube su `@version` y, al terminar, pasa al usuario el enlace
  para actualizarlo: `https://raw.githubusercontent.com/Adri2401/Scripts_Aurora/main/<fichero>` (uno por script tocado).
- Nunca tocar Voltorb Flip (`/trigal`), Ruinas Alfa (`/ruinas`) ni el Suelo Helado (`/hielo`).
- Nunca subir la cookie de sesión ni pedir que se pegue en el chat.
